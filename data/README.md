# data

## Data policy

This directory may contain only data that the team is legally permitted to redistribute and that is necessary for the project.

For external, licensed, restricted, or hosted datasets, document the source instead of committing the dataset itself.

For every referenced data source, record:

- Source name and authoritative URL
- License/usage terms
- Version or retrieval date
- Expected schema/format
- Reproduction/access instructions
- Any transformations applied before use

Never commit credentials, API keys, licensed datasets without redistribution rights, or confidential institutional data.
