# OSSP AI Agent Configuration & Guidelines

## Repository Philosophy
1. **Look and Feel:** Maintain high-quality markdown headers, tables, and shields/badges.
2. **Consistency:** Always keep content provided by the user and organize it into the Module-wise structure.
3. **Naming Convention:** Lab files must use the prefix `practical_weekN` or `skill_weekN`.
4. **Outputs:** Every folder must have a README.md that explicitly lists tasks and expected/actual outputs.

## Course Context
- Course: OSSP (Operating Systems and Systems Programming)
- Project: Shellforge (Unix shell in C)
- Methodology: Outside-In / PBL
