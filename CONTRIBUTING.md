# Contributing to Team 12

This repository is an academic team project. Contribution history is part of the project evidence, so all changes must remain attributable and authentic.

## Workflow

1. Work on a focused task.
2. Test the change locally.
3. Commit meaningful work from your own GitHub account.
4. Use clear conventional-style commit messages.
5. Keep documentation synchronized with implementation.
6. Reference the relevant phase/review when appropriate.

## Commit examples

```text
feat(allocator): implement free-list block splitting
test(allocator): add realloc preservation cases
feat(monitor): add proc status sampling
docs(project): update architecture and results
fix(allocator): correct block coalescing metadata
```

## Academic contribution rule

Do not bulk-upload another member's work, manufacture contribution history, or rewrite history to obscure authorship. The repository must demonstrate genuine progressive work by the team.

## Quality checklist

- [ ] Build succeeds
- [ ] Relevant tests pass
- [ ] No credentials/secrets added
- [ ] Documentation updated
- [ ] Generated files are not unnecessarily committed
- [ ] Contribution is attributable to the actual author
