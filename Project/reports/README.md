# `reports/` — Academic Deliverables

This directory contains formal project deliverables.

## Suggested layout

```text
reports/
├── reviews/
│   ├── review-1/
│   └── review-2/
└── final/
```

## Review package

Each review package should contain the applicable implementation snapshot, methodology, evidence, results and contribution summary.

## Final package

The final package should include the final report, validated results, demonstration evidence and any approved supporting material.

Use real measurements and reference the corresponding Git commit/tag. Do not claim completion for work that has not been demonstrated.
