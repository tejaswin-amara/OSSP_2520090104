# `data/` — Data & Inputs

This project does not require a conventional external dataset. The directory is reserved for **permitted, non-sensitive experiment inputs** and provenance documentation.

## Policy

Do not commit credentials, confidential institutional data, personal data, restricted datasets, or licensed data that cannot legally be redistributed.

For an external source, document:

- source/owner;
- URL or official identifier;
- version and retrieval date;
- license/usage terms;
- schema or input format; and
- reproduction/acquisition instructions.

Large generated logs belong in `../results/`, not here.
