# OSSP 2520090104

> Operating Systems & System Programming coursework repository

A clean, module-based workspace for practical work, skill activities, implementations, reports, and supporting coursework.

## Repository Layout

Every module follows the same structure:

```text
Module_XX_<Topic>/
├── README.md
├── Practical/
│   └── README.md
└── skills/
    └── README.md
```

- **Practical/** — laboratory exercises, programs, experiments, demonstrations, and practical submissions.
- **skills/** — skill activities, guided exercises, reports, and skill-based submissions.

## Organization Rules

1. Classify coursework by **what the material actually covers**, not by its filename alone.
2. Keep practical work in `Practical/` and skill work in `skills/`.
3. Keep each module self-contained.
4. Use descriptive filenames and task-specific subfolders when needed.
5. Keep generated files, IDE state, caches, datasets, and personal configuration out of the repository unless explicitly required coursework assets.
